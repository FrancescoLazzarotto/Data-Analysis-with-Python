# Data-Analysis-with-Python
Titanic Project - Data Analysis

Authors: Francesco Lazzarotto, Francesco Rolando
Course: Python Laboratory

Description

This project analyzes the Titanic passengers dataset (titanic_survivors.csv) using Python, pandas, and matplotlib.
The goal is to explore data distribution, analyze passenger survival based on variables such as class, sex, age, and presence of a spouse aboard, and compare ticket fares across classes.

Key analyses include:

Age distribution of passengers with histograms

Survival percentage by passenger class

Survival percentage by sex

Survival by combined class and sex

Impact of having a spouse aboard on survival

Ticket fare analysis per class (mean, min, max)

Technologies Used

Python 3.x

Pandas

Matplotlib






Dataset

The project uses the titanic_survivors.csv dataset. Make sure it is placed in the dataset/ folder before running the scripts.
